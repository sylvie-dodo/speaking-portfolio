## 목표

[engccer/speaking-portfolio](https://github.com/engccer/speaking-portfolio)(신명중 영어 말하기 평가)를 고쳐 **한국외국어대학교 프랑스어교육과** 말하기 포트폴리오 녹음 평가 도구로 쓴다.

| 항목 | 값 |
|---|---|
| 반 | 1개(1반) |
| 학생 | 15명(1·2학년 혼합). 학번과 이름으로 입장하며, 내부 번호는 명렬 순번 1~15 |
| 교사 | 명렬에서 학년이 빈 행(순번 16) |
| 대화문 | 프랑스어, 약 5편(편집 중). 학생마다 2편 추첨 |
| 듣기 음원 | 원음이 없어 ElevenLabs 합성 음원 10편 사용 |

## 끝낸 작업

- **학교 이름:** 화면 제목을 "한국외국어대학교 프랑스어교육과 말하기 포트폴리오"로, 탭 제목을 "프랑스어 말하기 녹음"으로 바꿨다.
- **한 반:** 입장 화면에서 반 선택을 없애고 `cls=1` 숨김 값을 쓴다. `open.py`·`close.py`는 인자가 없으면 1반에 적용한다.
- **번호 범위:** 1~20(`lib/number-combobox.js`의 `MAX_NUMBER`)이며, `scripts/seed_students.py`의 `MAX_NUMBER`와 같아야 한다.
- **명렬 적재:** `scripts/seed_students.py "<명렬 CSV>"`로 올린다. 열은 `번호`,`이름`이고 20번 행을 교사로 지정한다. 번호가 범위를 벗어나거나, 중복되거나, 20번 행이 없으면 중단한다.
- **프랑스어:**
  - 대사 `lang="fr"`
  - ElevenLabs 전사 `language_code: "fr"`
  - `scripts/scoring.py`의 `canonical()`: 악센트 유지, 엘리지옹·하이픈 분리, 프랑스어 숫자·서수·시각·€·°C·% 처리
- **추첨:** `drawExam`/`drawPractice`가 `dialogues.json`의 편 수를 받아 그 범위에서 뽑는다.

## 원본 저장소 병합(2026-10-21)

원본(`upstream`)의 10/19~10/20 커밋 5개를 병합했다. 학생 본인 점수 조회와 결과표 게시(`scripts/publish_scores.py`), 교사 대시보드 최종 점수, 전사 실패 재시도(`scripts/transcribe.py`), 후한 기준 비고(`scripts/scoring_generous.json`), 채점 임계값 보정이 들어왔다. 프랑스어 악센트 문자는 전사 의심 판정(라틴 확장 범위 밖 글자)에 걸리지 않는다.

## 학번 입장(2026-10-21)

- `supabase/migrations/20261021090000_student_ids.sql`: `students`에 `student_id`(유일)·`grade` 열을 추가했다. `resolve_student(학번, 이름)`은 둘 다 맞을 때만 `{class, number}`를 돌려준다. 교사 대시보드는 학번·학년도 보낸다.
- 입장 화면은 학번과 이름을 받는다. 번호 선택 목록(`lib/number-combobox.js`)은 삭제했다.
- `scripts/seed_students.py "<명렬.xlsx>"`는 검증만 하고, `--apply`를 붙이면 서버에 적재한다. 열은 순번, 학번, 학년, 이름이며 학년이 빈 행이 교사다.
- 교사 입장 정보는 짐작하기 쉬운 값이지만, 담당 교수가 그대로 쓰기로 결정했다(2026-10-21). 저장소에는 적지 않는다.
- Supabase 무료 플랜은 7일 동안 쓰지 않으면 일시정지된다. 그러면 CLI 연결이 `tenant/user not found`로 실패하며, 대시보드에서 Restore project로 복원한다.

## 대화문(2026-10-21)

- 원문은 `data/dialogues.md`(교수자 제공 샘플), 생성물은 `data/dialogues.json`이다. ID는 `P1-1`~`P1-5`(아침 일과 인터뷰, 화자 A·B)와 `P2-1`~`P2-3`(옷가게, 화자 Cécile·La vendeuse·Medhi)이다.
- 2026-10-22 독백 2편(장보기, Poulet Palava)을 파트 3(`P3-1`, `P3-2`)으로 추가했다. 독백은 문장마다 녹음 단위이며 화자 이름을 표시하지 않는다. 원문의 "pécialité"는 "spécialité"로 고쳤다.
- 본 평가는 파트 1·2·3에서 1편씩 3편을 학생별로 고정 추첨한다(`lib/draw.js`의 `partGroups`, `drawExam`). 모의 평가는 10편 중 무작위 1편이다. 채점표(`scripts/score.py`)도 파트 수만큼 대화 열을 만든다.
- `supabase/migrations/20261022090000_three_dialogues.sql`은 제출당 대화 수를 2~3편으로 넓힌다. `20261022091000_audio_wav.sql`은 audio 버킷에 WAV를 허용한다.
- 채점 표현은 대사를 문장 단위로 나눈 것이라 편마다 4~16개다. 편 점수는 `min(10, 1 + 10 × 통과 수 ÷ 표현 수)`(정수 나눗셈)이며, 표현 10개일 때 원작 점수표와 같다.
- 화면은 대사 앞에 화자 이름을 굵게 표시하고, 화자별로 색과 테두리(실선·이중선·점선)를 다르게 한다.
- 2026-10-22 교수자 확인으로 원문 세 곳을 고쳤다. 7번 "Voilà un trente-huit !" 오타, 2번 문장을 "C'est malheureux, mais la première chose que je fais, c'est le smartphone."으로 수정, 7번 감탄사 "Hmm…"은 삭제(전사가 불안정하므로).

## 합성 음원(2026-10-22)

- `scripts/generate_audio.py`가 대사마다 화자 목소리로 합성하고, 0.7초 쉼을 넣어 편별 WAV를 만든다. audio 버킷에 올린 뒤 `data/audio.json`에 대사 해시와 함께 기록한다.
- ElevenLabs 무료 요금제는 Voice Library(프랑스어 원어민) 목소리를 API로 쓸 수 없다(402 paid_plan_required). 그래서 계정 기본 목소리(영어 원어민)를 쓴다. 기본 목소리 중에는 프랑스어 원어민이 없다.
- 현재 배정(`scripts/tts_voices.json`)은 다음과 같다.
  - 파트 1: A Alice, B George(2·4번 Daniel), 1번의 두 번째 대답자 C Lily
  - 파트 2: Cécile Alice, 점원 La vendeuse Lily, Medhi Chris. 남성 점원(Eric, Roger)도 시험했지만 여성 점원으로 확정했다.
  - 독백: 장보기 Brian, 요리 Lily
- Cécile·점원은 Sarah, Matilda, Bella, Laura, Jessica를 들어 본 뒤 억양이 어색해 Alice·Lily로 정했다.
- 음원 파일 이름에 내용 해시를 붙인다(`P1-1-803af60494.wav`). 바꾸기 전에는 이름이 늘 같아, 휴대폰 브라우저가 1시간 동안 옛 음원을 재생했다(Supabase Storage `max-age=3600`). 다시 올리면 이전 파일은 버킷에서 지운다. 앱은 `dialogues.json`을 `no-cache`로 받는다.
- 합성기가 잘못 읽는 곳은 `tts_voices.json`의 `pronunciation`으로 합성 입력의 철자만 바꾼다. 화면·채점 원문은 그대로다. 현재 점원 대사 두 곳을 보정한다. "Quelle est votre taille"는 "Quelle è", "Quelle est votre pointure"는 "Quelle ait"로 읽힌다. 교수자가 들어 보고 골랐다.
- 모델은 `eleven_multilingual_v2`다. 프랑스어 지정 모델(turbo·flash v2.5)과 비교해 교수자가 이것이 낫다고 판단했다.
- 교수자가 원래 고른 원어민 목소리는 `library_cast_for_paid_plan`에 역할별로 적어 두었다. ElevenLabs에 $5 크레딧을 추가하면 이름만 바꿔 다시 만들 수 있다.
- 무료 요금제는 출처 표시가 필요하므로 음원 아래에 "음원: ElevenLabs 음성 합성"을 표시한다. 월 10,000자 한도이며 전체 대사는 약 3,600자다.

## 남은 작업(우선순위 순)
0. **배포 상태:** 2026-10-22 합성 음원 10편을 audio 버킷에 올리고 `data/audio.json`으로 연결해 배포했다. 모델은 `eleven_multilingual_v2`(교수자가 프랑스어 지정 모델보다 낫다고 판단)이다. 원문 1~3번의 "Qu'est-ce que", "Est-ce que" 하이픈을 고치고 해당 음원을 다시 만들었다.
1. **대화문 원문 수정 시:** `data/dialogues.md`를 고친 뒤 `python scripts/build_dialogues.py`로 다시 만든다.
2. **음원 수정 시:** 대사를 고치면 `build_dialogues.py`가 그 편의 음원 연결을 끊고 안내한다. `python scripts/generate_audio.py <편 ID> --upload` 후 `build_dialogues.py`를 다시 실행한다. 바뀐 대사만 다시 합성된다(`tts_cache/`).
3. **실제 입장 시험:** 배포한 사이트에서 교사와 학생 1명으로 입장해 본다. 대화문이 준비된 뒤에 한다.
4. **보안 검증:** `.venv/Scripts/python.exe -m pytest tests/test_rls.py -q`로 실서버 보안 정책을 확인한다.
5. **전사 키:** 자동 전사를 쓰려면 `.env`의 `ELEVENLABS_API_KEY`를 채운다.
6. **원작 학교 형식 정리:** `scripts/score.py`와 `scripts/publish_scores.py`가 원작 형식을 쓴다. 파일 이름 `3-01-05 …`, 결과표 `3학년 N반 말하기 포트폴리오 결과표.xlsx`, 시트 `3-N`, 번호 1~40(학번으로 바꿀지 검토), 대화 ID 패턴 `L\d-\d`가 그 예다. 프랑스어 대화 ID를 정할 때 함께 고친다.
7. **선택:**
   - 교사 대시보드 문구(반별 표시)를 정리한다.
   - `scripts/scoring.json`의 기준값(일치율, 최대 멈춤, WPM)이 프랑스어 학습자에게 맞는지 검토한다.
