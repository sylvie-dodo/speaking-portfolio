마지막 정리: 2026-10-21. 다음 작업 세션은 이 문서부터 읽는다.

## 목표

[engccer/speaking-portfolio](https://github.com/engccer/speaking-portfolio)(신명중 영어 말하기 평가)를 고쳐 **한국외국어대학교 프랑스어교육과** 말하기 포트폴리오 녹음 평가 도구로 쓴다.

| 항목 | 값 |
|---|---|
| 반 | 1개(1반) |
| 학생 | 15명, 번호 1~15 |
| 교사 | 1반 20번(명렬 20번 행에 교사 이름) |
| 대화문 | 프랑스어, 약 5편(편집 중). 학생마다 2편 추첨 |
| 교재 듣기 음원 | 약 5개(편집 중) |

## 끝낸 작업

- **학교 이름:** 화면 제목을 "한국외국어대학교 프랑스어교육과 말하기 포트폴리오"로, 탭 제목을 "프랑스어 말하기 녹음"으로 바꿨다.
- **한 반:** 입장 화면에서 반 선택을 없애고 `cls=1` 숨김 값을 쓴다. `open.py`·`close.py`는 인자가 없으면 1반에 적용한다.
- **번호 범위:** 1~20(`lib/number-combobox.js`의 `MAX_NUMBER`)이며, `scripts/seed_students.py`의 `MAX_NUMBER`와 같아야 한다.
- **명렬 적재:** `scripts/seed_students.py "<명렬 CSV>"`로 올린다. 열은 `번호`,`이름`이고 20번 행을 교사로 지정한다. 번호가 범위를 벗어나거나, 중복되거나, 20번 행이 없으면 중단한다.
- **프랑스어:**
  - 대사 `lang="fr"`
  - ElevenLabs 전사 `language_code: "fr"`
  - `scripts/scoring.py`의 `canonical()`: 악센트 유지, 엘리지옹·하이픈 분리, 프랑스어 숫자·서수·시각·€·°C·% 처리
- **추첨:** `drawExam`/`drawPractice`가 `dialogues.json`의 편 수를 받아 그 범위에서 뽑는다.

## 원본 저장소 병합(2026-10-21)

원본(`upstream`)의 10/19~10/20 커밋 5개를 병합했다. 학생 본인 점수 조회와 결과표 게시(`scripts/publish_scores.py`), 교사 대시보드 최종 점수, 전사 실패 재시도(`scripts/transcribe.py`), 후한 기준 비고(`scripts/scoring_generous.json`), 채점 임계값 보정이 들어왔다. 프랑스어 악센트 문자는 전사 의심 판정(라틴 확장 범위 밖 글자)에 걸리지 않는다.

## 남은 작업(우선순위 순)
0. **새 마이그레이션 적용:** 원본에서 병합한 마이그레이션 2개를 `supabase db push`로 서버에 적용한다(`.env`의 `SUPABASE_DB_PASSWORD` 사용).

1. **프랑스어 대화문:** 대화문 원본 형식을 확인하고 `scripts/build_dialogues.py`를 다시 쓴 뒤 `data/dialogues.json`을 만든다.
   - 지금 파일은 원본의 영어 9편(Lesson 5~7)이며, `ORDER`·`META`·`SPLITS`·독백도 영어 전용이다.
   - 원본 규칙은 "편마다 표현 10개"다(`build_dialogues.py`, 점수표 `dialogue_score`). 프랑스어 대화문에 맞는지 확인한다.
   - 데이터가 바뀌면 `tests/test_scoring.py`와 `tests/test_dialogues.py`의 데이터 의존 테스트(편 ID `L5-3` 등을 쓰는 것)를 새 ID로 고친다.
2. **음원 업로드:** `scripts/upload_audio.py`를 5개 음원 파일 이름에 맞게 고치고 올린다.
3. **명렬:** 명렬 CSV(학생 15명 + 20번 교사)를 받아 `seed_students.py`로 적재한다. 그다음 교사로 입장해 대시보드를 확인한다.
4. **보안 검증:** `.venv/Scripts/python.exe -m pytest tests/test_rls.py -q`로 실서버 보안 정책을 확인한다.
5. **전사 키:** 자동 전사를 쓰려면 `.env`의 `ELEVENLABS_API_KEY`를 채운다.
6. **원작 학교 형식 정리:** `scripts/score.py`와 `scripts/publish_scores.py`가 원작 형식을 쓴다. 파일 이름 `3-01-05 …`, 결과표 `3학년 N반 말하기 포트폴리오 결과표.xlsx`, 시트 `3-N`, 번호 1~40, 대화 ID 패턴 `L\d-\d`가 그 예다. 프랑스어 대화 ID를 정할 때 함께 고친다.
7. **선택:**
   - 화면 인사말이 "1반 3번 이름"으로 반을 표시한다. 한 반이라 필요 없으면 뺀다.
   - 교사 대시보드 문구(반별 표시)를 정리한다.
   - `scripts/scoring.json`의 기준값(일치율, 최대 멈춤, WPM)이 프랑스어 학습자에게 맞는지 검토한다.
